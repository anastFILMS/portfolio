# Медиа сайта

Сюда складываются видео и фото. Пока ролика нет, кнопка «Смотреть» открывает
плеер с сообщением «Шоурил скоро появится.» — вёрстка уже готова и ничего
не поедет.

## Структура

```
public/media/
├── camera.webp        камера первого экрана (готова)
├── titles/            PNG леттеринга ANASTASIA / BRICHKO (готовы)
├── projects/          видео для раздела WORK  ← пусто, ждём файлы
└── about/             web-копии фотографий (оригиналы в assets-source/photos/)
```

## Что нужно для раздела WORK

На каждое из пяти направлений — до трёх файлов:

| Поле          | Что это                                | Формат                           | Вес       |
|---------------|----------------------------------------|----------------------------------|-----------|
| `previewLoop` | Превью, играет при наведении           | mp4/webm, 3–6 сек, **без звука** | ≈до 2 МБ  |
| `poster`      | Первый кадр (виден до наведения)       | webp/jpeg, ≈1200 px по ширине    | 150–350 КБ|
| `reel`        | Мини-шоурил, открывается по кнопке     | mp4 H.264/AAC, 20–60 сек, со звуком | ≈8–20 МБ |

Пример: для направления с `id: 'fashion'` кладём
`projects/fashion-loop.mp4`, `projects/fashion-poster.webp`,
`projects/fashion-reel.mp4`.

Затем в `src/content/projects.ts`:

```ts
{
  id: 'fashion',
  // ...
  status: 'ready',                                 // было 'placeholder'
  poster:      'media/projects/fashion-poster.webp',
  previewLoop: 'media/projects/fashion-loop.mp4',
  reel:        'media/projects/fashion-reel.mp4',
  // temporaryPoster убрать — он был только на время вёрстки
}
```

> Путь пишется от папки `public/` — без домена и без `/portfolio/` в начале.
> Префикс адреса сайта подставляется сам (`src/lib/asset.ts`), поэтому одни
> и те же пути работают и локально, и на GitHub Pages.

### Пропорции: два разных поля

- `coverAspectRatio` — форма обложки в сетке. Задана по макету, менять
  под ролик не нужно.
- `reelAspectRatio` — реальные пропорции ролика. Их использует плеер.

Вертикальный ролик (`9 / 16`) в сетке остаётся горизонтальной обложкой,
а в плеере показывается целиком по высоте, без обрезки под 16:9.

## Фото для «Обо мне»

Лежат в `about/` как WebP-копии. Оригиналы — в `assets-source/photos/`,
пересборка копий: `python3 scripts/make-photo-webp.py`.

Пути и подписи — в `src/content/about.ts`. Тяжёлой обработки на фотографии
не накладывается: лица остаются лицами.

## Превью ссылки (og:image)

Файла нет, и тег `og:image` в `index.html` намеренно снят — битая ссылка
на превью хуже его отсутствия. Когда появится согласованная картинка
1200×630, положить её сюда и вернуть тег с абсолютным адресом.

## Как готовить видео

```sh
# loop-превью: без звука, 6 секунд, ширина 900px
ffmpeg -i исходник.mp4 -t 6 -an -vf "scale=900:-2" -crf 28 -movflags +faststart loop.mp4

# постер: кадр на первой секунде
ffmpeg -i loop.mp4 -ss 0.5 -frames:v 1 -q:v 4 poster.jpg
```
