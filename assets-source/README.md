# Исходные материалы

Оригиналы фотографий Анастасии в том виде, в котором их прислали:
байты не менялись. Сайт их не грузит — в `public/media/about/` лежат
web-копии (WebP, до 1600 px по длинной стороне), и данные ссылаются
именно на них.

Пересобрать web-копии после замены оригиналов:

```sh
python3 scripts/make-photo-webp.py
```

| `about-shooting-bubbles.png` | Съёмка среди мыльных пузырей | Коллаж «Обо мне», задний левый кадр; временная обложка «За кадром» |
| `about-speaking.png` | С микрофоном на выступлении | Коллаж «Обо мне», основной портрет |
| `about-headphones.jpeg` | В наушниках | Коллаж «Обо мне», переднее малое фото |
| `reserve-shooting-brick.png` | Съёмка у кирпичной стены | Резерв |
