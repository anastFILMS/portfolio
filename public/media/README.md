# Медиа сайта

Сюда складываются все видео и фото. Пока файла нет, на его месте стоит
оформленная заглушка с подписью — вёрстка уже готова и ничего не поедет.

## Структура

```
public/media/
├── projects/     видео для раздела WORK
├── about/        фото для блока «Обо мне»
└── og.jpg        картинка для превью ссылки в мессенджерах (1200×630)
```

## Что нужно для раздела WORK

На каждый проект — до трёх файлов:

| Файл     | Что это                                  | Формат                          | Вес      |
|----------|------------------------------------------|---------------------------------|----------|
| `loop`   | Превью, которое играет при наведении     | mp4/webm, 3–6 сек, **без звука**| до 2 МБ  |
| `poster` | Первый кадр лупа (пока видео грузится)   | jpg/webp                        | до 250 КБ|
| `reel`   | Мини-шоурил, открывается по клику        | mp4, 20–60 сек, со звуком       | до 15 МБ |

Пример: для проекта с `id: 'fashion-week'` кладём
`projects/fashion-week-loop.mp4`, `projects/fashion-week-poster.jpg`,
`projects/fashion-week-reel.mp4`.

Затем в `src/content/projects.ts` прописываем пути:

```ts
{
  id: 'fashion-week',
  title: 'Неделя моды',
  year: 2026,
  directions: ['FASHION', 'EVENT'],
  ratio: '4 / 5',
  loop:   'media/projects/fashion-week-loop.mp4',
  poster: 'media/projects/fashion-week-poster.jpg',
  reel:   'media/projects/fashion-week-reel.mp4',
}
```

Заглушка исчезнет сама.

> Путь пишется от папки `public/` — без домена и без `/portfolio/` в начале.
> Префикс адреса сайта подставляется сам (`src/lib/asset.ts`), поэтому одни
> и те же пути работают и локально, и на GitHub Pages.

## Фото для «Обо мне»

- `about/portrait.jpg` — портрет, вертикаль 4:5
- `about/backstage.jpg` — фото за работой, горизонталь 3:2

Пути прописываются в `src/content/about.ts` (поле `photo`). На фотографии
автоматически ложится дуотон в цвета сайта — специально обрабатывать не нужно,
подойдёт обычный кадр.

## Общий showreel (необязательно)

По брифу отдельный шоурил не обязателен для первой версии — его роль выполняет
сам раздел WORK. Если он появится, положить `showreel.mp4` и прописать путь
в `src/components/Hero.tsx` (проп `video` у `MediaSlot`).

## Как готовить видео

Лупы лучше пережимать — иначе страница будет тяжёлой:

```sh
# loop-превью: без звука, 6 секунд, ширина 900px
ffmpeg -i исходник.mp4 -t 6 -an -vf "scale=900:-2" -crf 28 -movflags +faststart loop.mp4

# постер: кадр на первой секунде
ffmpeg -i loop.mp4 -ss 0.5 -frames:v 1 -q:v 4 poster.jpg
```
