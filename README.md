# anastFILMS — сайт-портфолио

Одностраничный сайт-портфолио видеографа-монтажёра (Anastasia B.).
Собран по брифу: гранж-стилистика, параллакс в разделе WORK, loop-видео
на карточках, рваная бумага на стыках секций.

**Адрес:** https://anastfilms.github.io/portfolio/

## Публикация на GitHub Pages

Разовая настройка: **Settings → Pages → Source: GitHub Actions**.

Дальше всё само: каждый push в `main` запускает сборку
(`.github/workflows/deploy.yml`) и выкладывает сайт. Руками ничего собирать
и коммитить не нужно — папка `dist/` намеренно не в репозитории.

Запустить публикацию вручную можно во вкладке **Actions → Deploy to GitHub
Pages → Run workflow**.

### Важно про адрес сайта

Сайт живёт не в корне домена, а в подпапке `/portfolio/` — по имени
репозитория. Поэтому в `vite.config.ts` задан `base: '/portfolio/'`.
Если это не учесть, стили и шрифты будут запрашиваться из корня и вернут 404.

При переезде базу можно поменять, не трогая код:

```sh
VITE_BASE=/ npm run build              # свой домен, сайт в корне
VITE_BASE=/новое-имя/ npm run build    # репозиторий переименовали
```

При переходе на свой домен поправить ещё `og:url` и `og:image`
в `index.html` — превью ссылок в мессенджерах требует абсолютных адресов.

## Запуск

```sh
npm install
npm run dev      # разработка, http://localhost:5173
npm run build    # сборка в dist/
npm run preview  # посмотреть собранную версию
```

## Что нужно заполнить перед публикацией

Всё содержимое лежит в `src/content/` — верстку трогать не нужно.
Места, требующие внимания, помечены в коде значком ⚠️.

| Файл | Что заменить |
|------|--------------|
| `src/content/site.ts` | **Telegram, VK, телефон, email** — сейчас заглушки |
| `src/content/projects.ts` | Проекты для WORK: названия, годы, форматы, пути к видео |
| `src/content/experience.ts` | Реальные мероприятия и проекты |
| `src/content/about.ts` | Стаж (`years`), при желании — текст; пути к фото |
| `src/content/skills.ts` | Программы и навыки (обычно менять не нужно) |
| `public/media/` | Все видео и фото — см. `public/media/README.md` |

Пока медиафайлов нет, на их месте стоят оформленные заглушки с подписью,
что именно туда встанет. Как только файл появился и путь прописан —
заглушка исчезает сама.

## Дизайн

Палитра из мудборда: **Midnight Blue `#1E223D`** + **Exotic Orange `#F54F1B`**
плюс бумага `#E9E1D2`. Тема только цветная — светлой/тёмной по брифу нет.

Вся гранж-графика (рваная бумага, каракули, спрей-теги, скотч, полутон)
рисуется кодом — SVG и CSS, без растровых текстур. Поэтому она не мылится
на ретине, весит около нуля и перекрашивается сменой одной переменной.
Форма считается от `seed`, так что ни один разрыв бумаги не повторяется,
но между сборками остаётся тем же.

Шрифты (Oswald, Caveat, JetBrains Mono, Inter) вшиты в проект, а не
подключены с Google Fonts: сайт для российской аудитории, где внешний CDN
бывает недоступен. Обновить набор — `python3 scripts/fetch-fonts.py`.

## Доступность и производительность

- Полная навигация с клавиатуры, модалка закрывается по Esc
- `prefers-reduced-motion` отключает параллакс, зерно и рывки анимаций
- Параллакс не работает на экранах уже 900px — там он мешает смотреть работы
- Все анимации идут через `transform`/`opacity`, без перерасчёта раскладки
