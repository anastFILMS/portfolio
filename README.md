# anastFILMS — сайт-портфолио

Одностраничный сайт-портфолио видеографа и монтажёра **Анастасии Бричко**
(Москва). Реализован по ТЗ из пакета `anastfilms-claude-handoff-v1`:
спокойный тёмный фон, оранжевый акцентом, пять направлений в разделе WORK,
бумажные стыки между секциями.

**Адрес:** https://anastfilms.github.io/portfolio/

Стек: React 18 + TypeScript + Vite, Framer Motion (появление блоков),
Lenis (плавный скролл). Хостинг — GitHub Pages, база `/portfolio/`.

## Публикация на GitHub Pages

Разовая настройка: **Settings → Pages → Source: GitHub Actions**.

Дальше всё само: каждый push в `main` запускает сборку
(`.github/workflows/deploy.yml`) и выкладывает сайт. Руками ничего собирать
и коммитить не нужно — папка `dist/` намеренно не в репозитории.

Запустить публикацию вручную можно во вкладке **Actions → Deploy to GitHub
Pages → Run workflow**.

### Важно про адрес сайта

Сайт живёт не в корне домена, а в подпапке `/portfolio/` — по имени
репозитория. Поэтому в `vite.config.ts` задан `base: '/portfolio/'`.
Если это не учесть, стили, шрифты и медиа будут запрашиваться из корня
и вернут 404.

Пути к медиа внутри `src/content/` пишутся БЕЗ ведущего слеша
(`media/about/foo.webp`), а в рантайме прогоняются через `asset()` из
`src/lib/asset.ts` — он подставляет базу сборки. Абсолютная строка
`/media/foo` в рантайме ушла бы в корень чужого маршрута.

При переезде базу можно поменять, не трогая код:

```sh
VITE_BASE=/ npm run build              # свой домен, сайт в корне
VITE_BASE=/новое-имя/ npm run build    # репозиторий переименовали
```

При переходе на свой домен поправить ещё `og:url` в `index.html`.

## Что реально заполнено, а что ждёт материалов

Вёрстка и вся механика готовы и проверены в браузере. Часть **контента**
ещё не передана — ниже честный список. Заглушки нигде не притворяются
готовыми данными.

| Чего нет | Что стоит сейчас |
|---|---|
| Пять мини-шоурилов | Слоты, состояния и плеер работают; `status: 'placeholder'`, кнопка открывает «Шоурил скоро появится.» |
| Настоящие постеры работ | Временные обложки из архива, помечены полем `temporaryPoster` |
| Подтверждённые мероприятия | Показываются форматы съёмки и монтажа; список событий включится сам, как только его заполнят |
| Telegram, VK, телефон, почта | Каналы выведены неактивными + строка «Контакты скоро появятся». Фальшивых `t.me/username` и `href="#"` нет |
| Официальный знак DaVinci Resolve | Только название текстом — выдуманный логотип рисовать нельзя |
| Картинка для og:image | Тег снят, чтобы не обещать битое превью |

Всё содержимое лежит в `src/content/` — вёрстку трогать не нужно.

| Файл | Что там |
|------|---------|
| `src/content/projects.ts` | Пять направлений WORK: id, номер, сторона, маска, пропорции, пути к медиа |
| `src/content/site.ts` | Имя, марка, лид первого экрана, контакты, навигация |
| `src/content/experience.ts` | «На площадке»: список мероприятий либо форматы |
| `src/content/about.ts` | Точный текст «Обо мне» и три фотографии коллажа |
| `src/content/skills.ts` | Программы, направления работы, тексты состояний плеера |

### Как подключить ролик

1. Положить файлы в `public/media/projects/`
2. В `src/content/projects.ts` прописать `poster`, `previewLoop`, `reel`
   и поставить `status: 'ready'`; убрать `temporaryPoster`
3. Ориентиры: `previewLoop` — 3–6 сек без звука, ≈до 2 МБ, 720p достаточно;
   `poster` — webp/jpeg ≈1200 px, 150–350 КБ; `reel` — mp4 H.264/AAC,
   20–60 сек, ≈8–20 МБ

`coverAspectRatio` (форма кадра в сетке) и `reelAspectRatio` (реальные
пропорции ролика) — РАЗНЫЕ поля. Вертикальный ролик не обязан раздувать
ряд на десктопе: в сетке он идёт горизонтальной обложкой, а в плеере
показывается целиком по высоте.

## Дизайн

Палитра: фирменный синий `#1E223D` и оранжевый `#F54F1B`, фоны чёрные и
угольные (`#101013`, `#191A20`, `#171C2A`), бумага `#E6E0D7`. У каждой
секции свой мягкий градиент — одинаковой синей ткани на всех секциях нет.
Тема только цветная, переключателя нет.

**Материалы растровые.** В `public/textures/` лежат бумага, фактуры фона,
граффити и скотч; в `public/media/` — камера, PNG имени и фамилии,
фотографии. Формы кадров WORK и профили стыков — фиксированные SVG-маски
из пакета ТЗ (`public/design/`), привязанные к id направления: одна и та же
страница всегда выглядит одинаково. Процедурная генерация по seed осталась
только на бумажках первого экрана.

Леттеринг `ANASTASIA` / `BRICHKO` — отдельные PNG в `public/media/titles/`.
Это исходная база из проекта, а НЕ точные слои последнего макета: буквы
прототипа нарисованы иначе. Слои независимы — картинку можно заменить,
не перекладывая первый экран.

Шрифты локальные, не с Google Fonts: сайт для российской аудитории, где
внешний CDN бывает недоступен. Роли: **Oswald 700** — узкие заголовки
и названия работ; **Guano Apes** — граффити («Обо мне», «Снимем
что-нибудь?»); **Montserrat** — весь основной текст, кнопки и подписи;
**Splatink** — латинский леттеринг. Основной текст граффити-шрифтом
не набирается никогда.

## Доступность и движение

- Полная навигация с клавиатуры; контур фокуса виден и не срезан масками
  (рваный край кнопок рисует псевдоэлемент, а не `clip-path` на самой кнопке)
- Плеер — настоящая модалка: Tab и Shift+Tab не выходят наружу, фон помечен
  `inert`, Lenis остановлен, после закрытия фокус возвращается на вызвавшую
  кнопку, положение прокрутки восстанавливается
- В плеере native controls: пауза, перемотка, громкость, полный экран.
  Принудительных `muted loop` нет, звук не включается без действия
- `prefers-reduced-motion` отключает параллакс и появление блоков; настройка
  отслеживается на лету, а не только при загрузке
- Параллакс выключен на экранах уже 900 px
- Основной текст не мельче 16 px, подписи не мельче 13 px, зоны нажатия
  не меньше 44 px
